# RNA-Transformer

A learning and research project exploring Transformer architecture
and attention mechanisms for brain tumor classification using RNA-seq data.

## Learning goals
- Implement scaled dot-product attention using NumPy.
- Understand self-attention, multi-head attention, and cross-attention.
- Learn positional encoding, feed-forward networks, residual connections,
  and layer normalization.
- Implement Transformer components in PyTorch.
- Compare a Transformer classifier with simpler machine-learning baselines.

## Project status
Environment setup and project structure.

## Important
The RNA-seq dataset, class labels, and evaluation strategy must be verified
before finalizing the experiments. No model results are claimed yet.
